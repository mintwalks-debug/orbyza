# 🚀 Orbyza - Digital Excellence Engine

Elite digital marketing agency platform for Jaipur and Global markets. Built for high-velocity scaling and absolute search dominance.

## 🛠️ The 6-Tool Stack
This project is engineered using a sophisticated multi-tool integration:
1. **Antigravity**: Primary AI Coding Assistant (Strategy & Execution)
2. **GitHub**: Version Control Backbone & CI/CD Hub
3. **v0**: Initial UI Architecture & Component Generation
4. **Cursor**: High-Fidelity Logic Refinement & AI-Integrated Dev
5. **Supabase**: Direct Backend, Auth, and Dynamic Data Storage
6. **Vercel**: Global Edge Deployment & Performance Hosting

## 📁 Project Architecture
- `src/app`: Next.js 16 App Router (SEO & Performance Optimized)
- `src/components`: Cinematic Dark Mode UI Components
- `src/lib/supabase.ts`: Direct Supabase Integration (PostgreSQL)
- `src/data`: Intelligence Asset Repositories (Static & Dynamic)
- `.cursorrules`: AI Intelligence Protocol for Cursor IDE

## 🚦 Getting Started
1. **Clone & Install**:
   ```bash
   git clone [repo-url]
   npm install
   ```
2. **Environment Setup**:
   Populate `.env.local` with your Supabase, Google Analytics, and Vercel credentials.
3. **Database Initialization**:
   Run the SQL schema located in the `artifacts/supabase_schema.sql` (or provided in Antigravity brain) within your Supabase SQL Editor.
4. **Development**:
   ```bash
   npm run dev
   ```
